# job-hunting-os
Job Hunting OS is a reusable, personalized system for managing a next-role search. It helps a candidate develop their career materials, discover opportunities, build relationships, prepare for conversations, learn from interviews, and choose useful next actions. It should manage attention rather than create homework.

## Start here

1. Download [the blank tracker](Job-Hunting-OS-Tracker.xlsx).
2. Open [the Workspace Map](Workspace-Map.md) and make your own copy.
3. Follow the setup instructions below.
